Título del Artículo

Este es el primer párrafo del artículo. Contiene información importante sobre el widget Agent-Web y sus capacidades.

El widget permite interactuar con cualquier página web mediante comandos de voz. Es completamente client-side y respeta la privacidad del usuario.

Puedes hacer clic en botones, llenar formularios, buscar información y navegar por la página usando solo tu voz.

⚠️ Acciones Bloqueadas por Seguridad

El widget NO permitirá las siguientes acciones:

  • Hacer clic en campos de contraseña
  • Llenar campos de contraseña, tarjetas de crédito, CVC, SSN
  • Enviar formularios de login o pago
  • Navegar a URLs externas (fuera del mismo dominio)
  • Ejecutar scripts o código JavaScript
  • Acceder a iframes o elementos ocultos

Estas restricciones son por tu seguridad y privacidad.
